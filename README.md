## 🚀 Featured Projects

### 🛍️ Retail Customer Behavior & Shopping Trends Analysis

**Python • SQL • Power BI**

- Developed an end-to-end retail analytics solution to understand **shopping behavior, purchasing patterns, customer engagement, and repeat purchases**.
- Cleaned and transformed transaction data using **Pandas** and performed exploratory data analysis across demographics, categories, discounts, reviews, seasons, payment preferences, and purchasing frequency.
- Used **SQL** to analyze customer segments, loyalty patterns, and purchase drivers.
- Built an interactive **Power BI dashboard** to generate insights and support marketing and product strategy recommendations.

---

### 📉 Customer Churn Prediction & Retention Strategy

**SQL • Python • Machine Learning • Power BI • MLflow**

- Built an end-to-end churn prediction solution using **SQL Server** data to identify customers at risk of leaving.
- Benchmarked **Logistic Regression, Random Forest, XGBoost, LightGBM, and KNN** on imbalanced and SMOTE-balanced datasets.
- Achieved a **0.90 F1-score on the churned class using LightGBM**.
- Applied **LIME explainability** to understand individual customer churn predictions.
- Integrated customer-level predictions into **Power BI** to identify churn drivers and support targeted retention strategies.

---

### 👥 Customer RFM Segmentation & Customer Lifetime Value Modeling

**SQL • Python • Power BI**

- Developed an **RFM-based customer segmentation** solution to identify high-value, loyal, at-risk, and lost customers.
- Used SQL **NTILE window functions** to score customers based on Recency, Frequency, and Monetary value.
- Combined RFM segmentation with **Customer Lifetime Value (CLV)** modeling.
- Built Power BI analysis to translate customer value into differentiated **retention and marketing recommendations**.
